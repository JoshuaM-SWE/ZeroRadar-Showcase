## ✨ Overview

**ZeroRadar** is a price-tracking application built to make it easier to follow products without repeatedly checking their pages. Users can submit a product link, view its price history, and receive email notifications when a tracked price drops.

## 🚀 Features

- **Product tracking** — Submit a product link to start monitoring its price.
- **Price history** — View previous prices and changes over time.
- **Email alerts** — Receive notifications when a tracked product drops in price.
- **Accounts & saved data** — Use Supabase authentication and database services.
- **Responsive interface** — Built with React, Next.js, and shadcn/ui.
